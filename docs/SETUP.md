# PSP Homebrew Setup

## Immediate goal

Build a minimal PSP homebrew program that produces an `EBOOT.PBP` file and runs in PPSSPP.

## Planned environment

- PSP homebrew SDK
- C or C++
- PPSSPP for testing

## Repository layout

- `src/` — source code
- `assets/` — game resources such as images, fonts, and audio
- `docs/` — setup notes and project documentation

## Build output

Generated build files and packaged PSP output must not be committed to Git. They are excluded through `.gitignore`.

## Next milestone

Create a minimal PSP program that shows a visible first screen in PPSSPP.
