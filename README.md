# Film After Midnight

> A small atmospheric 2D RPG for PSP homebrew.

**Film After Midnight** is a short interactive walk through an empty film studio after a night shoot.

A young camera operator stays behind to find a missing film reel, speak with a projectionist, and unlock the way out.

## Project goal

This repository is a practical GitHub learning project.

The goal is to build a small working PSP homebrew game while learning a real development workflow:

- issues
- branches
- commits
- pull requests
- reviews
- merges
- tags and releases

## MVP

The first playable version includes:

- One small screen-sized location
- A controllable player character
- Four-direction movement
- Wall boundaries and collision
- One projectionist NPC
- A short dialogue sequence
- One collectible film reel
- An exit that opens after the reel is collected
- A final screen
- A build that runs in PPSSPP and later on a PSP

## Development status

The project is at the initial documentation stage.

## Planned technology

- PSP homebrew SDK
- C or C++
- PPSSPP for testing

## Repository workflow

The `main` branch contains verified project states.

Each independent feature or fix is developed in its own branch and merged into `main` through a pull request.
